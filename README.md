# Grocery Management System

A PHP + MySQL grocery inventory and billing management system with Admin LTE 4 styling.

## Features
- Product management
- Purchase tracking
- Sales tracking
- Inventory monitoring
- GST summary (CGST, SGST, IGST)
- AdminLTE 4 dashboard layout

## Requirements
- PHP 8+
- MySQL 5.7+
- Apache or Nginx
- Composer not required

## Setup
1. Start Apache/MySQL.
2. Open `setup.php` in your browser.
3. Click `Create Database & Tables`.
4. Open `index.php` or `products.php` to use the application.

## Default DB Credentials
- Host: localhost
- Database: grocery_db
- Username: root
- Password: empty

## Notes
This project is designed as a small shop management system for grocery sales, purchases, stock, and GST calculations.
